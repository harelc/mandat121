# המנדט ה־121

מעקב אזרחי חי אחרי הכנסת: כל חוק, כל הצבעה, כל ח״כ — נבנה ישירות מה־OData
הרשמי של הכנסת. 120 מנדטים חולקו ביום הבחירות; המנדט ה־121 נשאר אצל
האזרחים, ועובד כל הקדנציה.

- **האפליקציה**: `index.html` בשורש הריפו (קובץ יחיד, נתונים סטטיים מ־`data/`)
- **תוכנית ומפת דרכים**: `ROADMAP.md` · מסמך העיצוב: `OPEN_KNESSET.md` · מדריך ה־API: `KNESSET_APIS.md`
- **בונים**: `build_*.py` (stdlib בלבד) קוראים את ה־OData הרשמי וכותבים snapshot־ים ל־`data/`
- **הרצה מקומית**: `python3 -m http.server 8092` ולפתוח את `http://localhost:8092/`
- **רישיון**: הקוד ברישיון MIT, תוכן האתר CC BY-NC-SA 4.0, נתוני צד־שלישי (הכנסת, ויקיפדיה, ויקינתונים) בתנאיהם — פירוט ב־`LICENSE`

## biapia

המשחק ביע־פיע חי כעת בתיקיית `biapia/` (עם ה־README והבונים שלו), ופורסם
כאתר נפרד. הפריסה שלו מורכבת בזמן build מהנתונים המשותפים שב־`data/`
(ראו `biapia/build_site.sh` ו־`biapia/netlify.toml`).
